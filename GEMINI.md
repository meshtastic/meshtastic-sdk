# Meshtastic Kotlin SDK project instructions

`meshtastic-sdk` is a Kotlin Multiplatform SDK for [Meshtastic](https://meshtastic.org) nodes. It talks the PhoneAPI to a node over Bluetooth LE, TCP or USB serial from Android, JVM and iOS, and over the node's WebSocket phone API from those targets and from Kotlin/JS and Kotlin/Wasm hosts.

[`AGENTS.md`](./AGENTS.md) holds the repository's agent guidance, commands and architecture rules. Where this file disagrees with it, `AGENTS.md` wins.

## Stack

- Kotlin Multiplatform: JVM, Android, iOS (`iosArm64`, `iosX64`, `iosSimulatorArm64`), plus `js` and `wasmJs` on `:core`, `:testing` and `:transport-websocket`.
- Coroutines, `Flow` and `StateFlow`; the engine is a single-writer actor.
- Protobuf types generated by Wire, from the published `org.meshtastic:protobufs` artifact.
- Storage: SQLDelight in `:storage-sqldelight`.
- Transports: Kable (Bluetooth LE), Ktor sockets (TCP), jSerialComm and usb-serial-for-android (serial), Ktor client (WebSocket).
- Tooling: Gradle Kotlin DSL with convention plugins in `build-logic/`, Spotless, detekt, Kover, Dokka V2, the Kotlin Gradle plugin's ABI validation (`checkKotlinAbi`), and SKIE for the iOS frameworks.

## Architecture

`docs/SPEC.md` and `docs/architecture/` describe it:

- `RadioClient` is the public facade, built with `RadioClient.Builder`.
- `MeshEngine` is an actor: one coroutine draining a channel of engine messages. All engine state changes happen inside it, without mutexes.
- The handshake is an explicit two-stage state machine (`docs/architecture/handshake-fsm.md`).
- `CommandDispatcher` allocates `request_id`s and tracks admin RPCs.
- Outbound sends return a `MessageHandle` whose state moves Queued → Sent → Acked, Delivered or Failed.
- Transport modules implement `RadioTransport`; storage is keyed by `TransportIdentity`.

## Commands

- Full gate: `./gradlew check` (build, tests, Spotless, detekt, `checkKotlinAbi`, `:core:verifyModuleBoundary`).
- Tests: `./gradlew allTests`, or `./gradlew jvmTest` while iterating.
- Format: `./gradlew spotlessApply`.
- API docs: `./gradlew dokkaGenerate` (Dokka V2; aggregated HTML under `build/dokka/html`).
- ABI dumps: `./gradlew checkKotlinAbi`, and `./gradlew updateKotlinAbi` after an intentional public API change.
- CLI sample: `./gradlew :samples:cli:installDist`, then `samples/cli/build/install/cli/bin/cli --help`.

## Conventions

- Public API shapes (ADR-005): a `suspend fun` that throws `MeshtasticException` for fatal or programmer errors, typed sealed outcomes (`SendOutcome`, `AdminResult`) for expected mesh failures, and `Flow` or `StateFlow` for streams and state. No `kotlin.Result<T>`.
- Use the Wire-generated types (`org.meshtastic.proto.*`) directly in the public API. Their fields are `snake_case` (`user.long_name`).
- No `Mutex` or atomics on engine paths. No `java.*` or `android.*` in `commonMain`; use `okio.ByteString` for bytes and `kotlinx-datetime` for time.
- Every public symbol has KDoc.
- Tests use `FakeRadioTransport` from `:testing` and `InMemoryStorageProvider` from `:core`, with `kotlin.test`, Turbine and Kotest assertions.
- Commits are signed off for the DCO (`git commit -s`). Changelog entries are fragments in `changelog.d/`.

## Key paths

- `docs/SPEC.md`: implementation plan.

- `core/`: engine and public API.
